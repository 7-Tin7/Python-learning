| 项目 | 说明 | 技术要点 |
|------|------|---------|
| 购物清单 | 增删物品的清单管理 | 列表 `append/remove`、`enumerate` |

| 手机号整理器 | 格式化手机号并打码 | 切片、`replace` 清洗数据 |
| 日期格式转换器 | 年月日的多种格式互转 | 切片 + `split`/`join` |
| 迷你计算器 | 函数版四则运算 | `def`、参数、`return` |
| 三角洲仓库管理 | 原创：游戏物资仓库与资产统计 | 字典查价、`join`、输入校验 |
