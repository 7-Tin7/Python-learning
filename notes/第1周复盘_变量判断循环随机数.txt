一、核心知识理论精讲
────────────────────────────────────────

【1.1 变量 —— 存数据的"盒子"】
  Python 是"动态类型"语言：不需要提前声明变量类型。
  name = "小明"      # 字符串
  age = 18           # 整数
  height = 1.75      # 小数
  规则：名字用字母/数字/下划线，不能数字开头，避开关键字(if/while/def...)
  记忆：等号 = 是"赋值"，把右边的东西装进左边的盒子。

【1.2 本周的 4 种数据类型】
  int(整数)    42, -3
  float(小数)  3.14, 2.0
  str(字符串)  "你好"（必须有引号）
  bool(布尔)   True / False（判断的结果，首字母大写！）

【1.3 input 和 print —— 程序的"耳朵和嘴巴"】
  input("提示语")   ← 等待用户输入，【永远返回字符串】！
  print(内容)       ← 在屏幕上显示
  f-string 格式化：print(f"我叫{name}，今年{age}岁")
    大括号 {} 里的变量会被替换成实际值。
    忘记写 f 前缀 → 会原样打印出 {name} 这几个字（第2周踩过的坑）

【1.4 类型转换】
  int("3")   → 3    （字符串转整数）
  float("3.5") → 3.5
  崩溃警告：int("abc") 会直接报 ValueError 崩溃！
  【重要】input() 出来的是字符串，要运算必须先转换。

【1.5 比较运算符】
  > 大于   < 小于   >= 大于等于   <= 小于等于   == 等于   != 不等于
  铁律：不同类型永远不相等！
    3 == "3"  → False（数字 3 和文字"3"不是一回事）
    1 == "1"  → False
  所以判断输入时：choice == "1"（字符串比较要加引号）

【1.6 if / elif / else —— 分支判断】
  if 条件:
      做A
  elif 另一个条件:
      做B
  else:
      做C
  - 从上往下检查，谁先成立执行谁，只执行一个分支
  - elif 可以有很多个，else 可有可无
  - or = 或者（满足一个就行）；and = 并且（全部满足才行）

【1.7 while 循环 + break + continue】
  while True:          # 无限循环
      ...
      break            # 退出整个循环（游戏结束）
      continue         # 跳过本轮剩余代码，回到循环开头（重新输入）
  死循环风险：条件永远为真且没有 break → 程序卡死
  应用：菜单程序、猜数字、游戏主循环——第 1、2 周所有项目都是它！

【1.8 for 循环 —— 数次数/遍历用】
  for x in range(3):   # range(3) = 数字 0,1,2 → 循环 3 遍
  for item in 列表:    # 遍历列表的每个元素（第2周主用）
  记忆：循环跑几遍 = range 里有几个数字 / 列表有几个元素

【1.9 random 模块 —— 让程序有随机性】
  import random                # 先导入
  random.randint(1, 100)       # 随机整数：1~100 之间
  random.choice(["石头","剪刀","布"])  # 从列表里随机挑一个

【1.10 缩进 —— Python 最重要的语法！（本周最大坑）】
  Python 不用花括号 {} 分块，用【缩进】！
  - 同一个代码块的缩进必须一模一样（一般 4 空格或一个 Tab）
  - 缩进多了/少了 → IndentationError
  - 想象成"楼层"：while/if/else 后面缩进一层 = 上一楼；
    循环/判断结束 = 回到原来的楼层
  - VS Code 技巧：Tab 缩进、Shift+Tab 退回、Ctrl+A 全选后重排

【1.11 数字检查小工具 isdigit()】（掷骰子大战学的）
  "85".isdigit()   → True   （是纯数字）
  "abc".isdigit()  → False
  "85.5".isdigit() → False  （有小数点不算纯数字）
  用途：先检查是不是数字，再 int() 转换 → 不会崩溃
  核心顺序：【先检查，后转换】（第 2 周成绩系统又用到了！）

二、三个练习项目详解

【项目 1：猜数字】
  规则：电脑随机想 1~100 的数，你猜，电脑提示大小，猜中结束。

  import random
  secret = random.randint(1, 100)   # 电脑想的数
  guesses = 0                       # 计数器

  while True:
      guess = int(input("请输入你猜的数字："))   # 输入转整数
      guesses = guesses + 1                     # 累加套路：猜一次+1

      if guess > secret:          # 猜大了
          print("太大了！")
      elif guess < secret:        # 猜小了
          print("太小了！")
      else:                       # 既不大也不小 = 猜中
          print(f"恭喜你！猜了 {guesses} 次！")
          break                   # 跳出循环
  考点：random.randint / while True / if-elif-else / break / 累加计数

【项目 2：石头剪刀布】
  规则：和电脑对战，q 退出，显示比分。

  import random
  player_score = 0
  computer_score = 0

  while True:
      player = input("请输入：石头/剪刀/布（输入 q 退出）：")
      if player == "q":                    # 退出判断在转换之前！
          print(f"最终比分 你 {player_score} : {computer_score} 电脑")
          break

      computer = random.choice(["石头", "剪刀", "布"])

      if player == computer:               # 平局
          print(f"你出了{player}，电脑出了{computer}，平局！")
      elif (player == "石头" and computer == "剪刀") or \
           (player == "剪刀" and computer == "布") or \
           (player == "布" and computer == "石头"):
          player_score = player_score + 1
          print(f"你出了{player}，电脑出了{computer}，你赢了！")
      else:                                # 其余情况都是电脑赢
          computer_score = computer_score + 1
          print(f"你出了{player}，电脑出了{computer}，电脑赢了！")
  考点：random.choice / or 连条件 / 计分 / 换行续写用反斜杠 \
  （注意：Python 换行续写是 \ 反斜杠，不是 / 正斜杠！）

【项目 3：掷骰子大战】
  规则：和电脑各掷 1~6 点骰子比大小，q 退出。
  特点：第一次引入【输入验证】——不合法就重新输入！

  import random
  player_score = 0
  computer_score = 0

  while True:
      player = input("请输入骰子数(1~6)/输入q退出:")
      if player == "q":                        # ① 先检查退出
          print(f"你的最终得分{player_score}:电脑的最终得分{computer_score}")
          break
      if not player.isdigit():                 # ② 检查是不是数字
          print("请输入数字！")
          continue
      player = int(player)                     # ③ 安全了才转换
      if player > 6 or player < 1:             # ④ 检查范围
          print("请输入正确范围！")
          continue

      computer = random.randint(1, 6)          # 电脑掷骰子
      # 然后比大小计分（和石头剪刀布一样，略）
  考点：isdigit / continue / 范围检查 / 三道关卡顺序：
        退出 → 数字 → 范围 → 转换 → 处理

────────────────────────────────────────
三、本周踩坑记录（血的教训，背下来）
────────────────────────────────────────
  坑 1：int("q") 崩溃
        → input 里套 int()，输入非数字就崩
        → 解法：先拿字符串判断，确认安全再转换
  坑 2：choice == 1 永远不成立
        → input 返回字符串 "1"，和数字 1 永远不等
        → 解法：比较时两边类型一致（choice == "1"）
  坑 3：缩进没缩 / 多缩
        → 游戏逻辑跑到 while 外面（只执行一次）
        → 或 else 前面夹了别的语句（语法错误）
        → 解法：楼层比喻，写完循环检查"回没回楼层"
  坑 4：or/ 写错
        → Python 换行续写用反斜杠 or\
        → or/ 会把 / 当成除法 → 语法错误

四、万能骨架（第 1、2 周所有项目的共同模板！）
────────────────────────────────────────

五、离线自测题（先自己答，再看答案）
────────────────────────────────────────
  Q1. input() 返回的是什么类型？运算前要做什么？
  Q2. 判断一个输入是否等于数字 5，正确写法是？
  Q3. break 和 continue 的区别？
  Q4. random.randint(1, 6) 和 random.choice(["a","b"]) 分别做什么？
  Q5. 写一个循环，让用户不断输入数字，输入 q 退出（口述逻辑）
  Q6. 为什么缩进错误会导致程序不按预期运行？
  Q7. "abc".isdigit() 和 "123".isdigit() 的结果是？
  Q8. while True 循环里没有 break 会怎样？
  Q9. 字符串 "10" + "3" 的结果是？为什么？
  Q10. 石头剪刀布判断"你赢"为什么用 or 连接 3 个条件？

  【答案】
  A1. 字符串(str)。要转 int() 或 float() 才能运算。
  A2. choice == "5"（字符串比较，加引号）。写成 == 5 永远不成立。
  A3. break 退出整个循环；continue 跳过本轮回到循环开头。
  A4. randint 生成 1~6 的随机整数；choice 从列表随机挑一个元素。
  A5. while True: x=input(); if x=="q": break; 再处理 x。
  A6. Python 用缩进分块，缩进错 = 代码进错块 = 逻辑错或 IndentationError。
  A7. False 和 True（isdigit 只认纯数字字符）。
  A8. 死循环，程序永不结束。
  A9. "103"——字符串做 + 是拼接不是加法！必须先 int() 转换。
  A10. 你赢有 3 种互斥情况（石>剪、剪>布、布>石），
       满足任意一种都算赢，所以用 or（"或者"）。
