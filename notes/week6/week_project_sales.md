## 三、数据清洗"五件套"（本项目核心新知识）

### ① 查看缺失值
```python
df.isnull().sum()          # 每列有几个缺失值
df[df["城市"].isnull()]    # 看具体哪些行缺城市
```

### ② 处理缺失值
```python
df = df.dropna(subset=["数量"])        # 删除"数量"缺失的行（关键字段缺失→删）
df["城市"] = df["城市"].fillna("未知")  # 城市缺失→填"未知"（保留数据）
```
**判断原则**：关键字段（数量/单价）缺失 → **删除**；非关键字段（城市）缺失 → **填充**

### ③ 删除重复行
```python
df.duplicated().sum()          # 有几行重复
df = df.drop_duplicates()      # 去重
```

### ④ 清理文本空格（.str 访问器！）
```python
df["类别"].unique()            # 先看看：['水果', ' 蔬菜', '饮料 ', ...] 有多余空格
df["类别"] = df["类别"].str.strip()   # 去掉首尾空格
df["类别"].unique()            # 再看：['水果', '蔬菜', '零食', '饮料'] ✅
```
**`.str` 是 Pandas 的"字符串操作器"**：`.str.strip()` 去空格、`.str.upper()` 转大写、`.str.replace()` 替换……

### ⑤ 过滤异常值 + 类型转换
```python
df = df[df["数量"] > 0]        # 数量必须为正数（过滤负数）
df = df[df["单价"] > 0]        # 单价必须大于 0
df["数量"] = df["数量"].astype(int)      # 转成整数（缺失值让这列变成了小数）
```

### ⑥ 日期格式统一（.dt 访问器）
```python
df["日期"] = pd.to_datetime(df["日期"])   # 统一转成日期类型（能自动识别多种格式！）
df["月份"] = df["日期"].dt.month          # 提取月份（.dt 访问器）
```
**`.dt` 是日期操作器**：`.dt.month` 月、`.dt.year` 年、`.dt.day` 日、`.dt.dayofweek` 星期几

## 四、分析任务清单

| # | 分析任务 | 涉及技术 |
|---|---------|---------|
| 1 | 新增"销售额"列 = 单价 × 数量 | `df["销售额"] = df["单价"] * df["数量"]` |
| 2 | 各类别销售额汇总 | `groupby("类别")["销售额"].sum()` |
| 3 | 月度销售趋势 | `groupby("月份")["销售额"].sum()` |
| 4 | 城市销售额排名 | `groupby("城市")["销售额"].sum().sort_values(ascending=False)` |
| 5 | 销量 Top 5 商品 | `groupby("商品名称")["销售额"].sum().nlargest(5)` |
| 6 | 关键指标 | 总销售额、总订单数、平均客单价 |
