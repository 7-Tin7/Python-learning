## 一、万能骨架（所有项目都是它！）

```python
# 第 1 步：初始化 —— 准备"容器"（变量 / 列表 / 字典）
容器 = []

# 第 2 步：主循环（游戏/程序永不结束，直到用户退出）
while True:
    # 第 3 步：显示当前状态（清单 / 仓库 / 通讯录 / 比分）
    # 第 4 步：显示菜单，获取用户输入
    choice = input("请选择：")
    # 第 5 步：if / elif / else 分支处理每个选项
    # 第 6 步：退出选项里 break
```

**记住这个骨架，所有项目都能对号入座。**

## 三、知识链条（一个概念接着一个概念）

```
变量（装 1 个东西）
   ↓ 升级
列表（装一堆东西）        ← 购物清单
   ↓ 限制
元组（装一堆但不能改）    ← 好友统计（enumerate 里见过）
   ↓ 特色
集合（自动去重）          ← 好友统计（年龄去重）
   ↓ 进化
字典（用名字找东西）      ← 通讯录、仓库查价
```

**每个新知识都是旧知识的"升级版"**，所以你总觉得"似曾相识"——因为本来就是一脉相承的！

## 五、复习方法（防止再乱）

1. **闭眼回忆法**：不看代码，说出每个项目的"容器"是什么（变量？列表？字典？）
2. **骨架套用法**：看一个新项目，先找它的"骨架六步"在哪
3. **遗忘不可怕**：编程的学习目标是"**看得懂 + 会改**"，不是"背下来"。忘了语法翻笔记（`notes/week2/`），比硬记强一百倍
