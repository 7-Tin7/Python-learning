一、Matplotlib 数据可视化
────────────────────────────────────────

【1.1 基本流程（4 步）】
  import matplotlib.pyplot as plt

  plt.bar(x, y)            # ① 画图
  plt.title("标题")         # ② 加说明
  plt.xlabel("X轴"); plt.ylabel("Y轴")
  plt.show()               # ③ 显示

【1.2 三种基础图（按用途选）】
  plt.plot(x, y)      折线图 —— 看【趋势】（随时间变化）
  plt.bar(x, y)       柱状图 —— 比较【大小】
  plt.scatter(x, y)   散点图 —— 看【关系】（如价格 vs 销量）
  plt.barh(x, y)      横向柱状图 —— 类别名较长时更好看
  plt.pie(值, labels=类别)  饼图 —— 看【占比】

【1.3 ⚠️ 中文显示（必设！否则变方块 □□□）】
  plt.rcParams["font.sans-serif"] = ["SimHei"]     # 黑体
  plt.rcParams["axes.unicode_minus"] = False       # 负号正常显示
  （Windows 用 SimHei；Mac 可用 Arial Unicode MS）

【1.4 常用设置】
  plt.figure(figsize=(10, 6))      # 图片大小（宽,高）英寸
  plt.title("标题")
  plt.xlabel("X 轴名"); plt.ylabel("Y 轴名")
  plt.grid(True, alpha=0.3)        # 网格（alpha 透明度）
  plt.xticks(rotation=45)          # X 轴文字旋转防重叠
  plt.legend()                     # 图例（多数据系列时必须加 label）
  plt.tight_layout()               # 自动调整布局（防标签被裁）

【1.5 保存图片】
  plt.savefig("图.png", dpi=150)   # ⚠️ 必须在 show() 之前！
  plt.show()
  （写反了会保存出空白图）

【1.6 子图（一图多张）】
  plt.figure(figsize=(15, 5))
  plt.subplot(1, 3, 1)      # 1行3列，第1个
  plt.bar(...)
  plt.xticks(rotation=90)   # ⚠️ 设置写在【对应子图内部】！
  plt.subplot(1, 3, 2)
  plt.bar(...)
  plt.tight_layout()        # 所有子图画完后统一调整
  plt.savefig(...)          # 别忘保存！
  plt.show()

  ⚠️ 关键坑：plt.xxx() 只作用于"当前子图"（最近一次 subplot 指定的）
     写在最后的 xticks/grid 只会影响最后一个子图！

【1.7 横向柱状图（barh）的坐标轴是反的！】
  plt.barh(类别, 数值)
  plt.xlabel("数值（如销售额）")   # ✅ X 轴是【数值】（柱子长度）
  plt.ylabel("类别名")             # ✅ Y 轴是【类别】

【1.8 饼图没有坐标轴！】
  plt.pie(值, labels=类别, autopct="%.1f%%", startangle=90)
  # autopct 显示百分比；不要加 xlabel/ylabel/grid（无效）

二、数据清洗"五件套"（本周核心）
────────────────────────────────────────

【2.1 查看污染情况】
  df.isnull().sum()             # 每列有几个缺失值
  df.duplicated().sum()         # 有几行重复
  df["列"].unique()             # 取值有哪些（查多余空格！）
  df["数量"].min()              # 最小值（查负数）

【2.2 处理缺失值】
  df.dropna(subset=["数量"])         # 关键字段缺失 → 删除整行
  df["城市"].fillna("未知")          # 非关键字段 → 填充
  【判断原则】关键字段（影响计算）缺失→删；非关键→填

【2.3 删除重复行】
  df.drop_duplicates()

【2.4 清理文本空格（.str 访问器）】
  df["类别"].unique()                     # 先看：['水果', ' 蔬菜', '饮料 '] ← 有空格！
  df["类别"] = df["类别"].str.strip()      # 去掉首尾空格
  # 效果：类别从 7 种纠正为 4 种（否则分组统计会出错）
  .str 访问器常用：.str.strip() / .str.upper() / .str.replace() / .str.contains()

【2.5 过滤异常值 + 类型转换】
  df = df[df["数量"] > 0]           # 过滤负数量
  df = df[df["单价"] > 0]           # 过滤 0 单价
  df["数量"] = df["数量"].astype(int)   # 缺失值会让整数列变成小数，需转回

【2.6 日期格式统一（.dt 访问器）】
  # 情况 A：格式统一
  df["日期"] = pd.to_datetime(df["日期"])

  # 情况 B：格式不统一（如混入 "2026/1/09"）→ pandas 3.0 会报错！
  #   ValueError: time data "2026/1/09" doesn't match format "%Y-%m-%d"
  # 解法 1（根治，推荐）：先统一格式再转
  df["日期"] = df["日期"].str.replace("/", "-")
  df["日期"] = pd.to_datetime(df["日期"])
  # 解法 2（绕过）：让 pandas 逐个识别
  df["日期"] = pd.to_datetime(df["日期"], format="mixed")
  # 解法 3（排查用）：无法解析的变 NaT —— 会丢数据，只适合先排查
  pd.to_datetime(df["日期"], errors="coerce")

  df["月份"] = df["日期"].dt.month      # .dt 访问器提取
  .dt 常用：.dt.year / .dt.month / .dt.day / .dt.dayofweek

【2.7 清洗顺序（标准流程）】
  删重复 → 处理缺失 → 清理文本 → 过滤异常 → 类型转换 → 日期处理

三、分析思维（比函数更重要！）
────────────────────────────────────────

【3.1 相关系数 .corr()（数值 ↔ 数值）】
  df["价格"].corr(df["销量"])       # -0.555
  读法：+1 强正相关 / 0 无关 / -1 强负相关
  ⚠️ 只能用于【两个数值变量】！

【3.2 分类变量（文字）不能算相关系数！】
  类别（水果/蔬菜）是"标签"，没有大小关系 → 不能算相关。
  错误做法：把类别编码成数字再算相关
    编码顺序 A（水果0/蔬菜1/零食2/饮料3）→ 相关系数 +0.527
    编码顺序 B（饮料0/零食1/蔬菜2/水果3）→ 相关系数 -0.527
    同一份数据，只换编号顺序结果就反了 → 证明毫无意义！
  ✅ 正确做法：分组比较（groupby 算各类的平均/总和，然后比较差异）
     说"类别间销量【差异明显】"，不说"类别与销量相关"

【3.3 groupby 结果怎么变回表格？】
  grouped = df.groupby("类别")["销售额"].sum()
  ## 此时"类别"是索引（index），不是普通列
  tmp = grouped.reset_index()      # ✅ 变回普通表格，类别成为一列
  之后可继续：筛选 / 排序 / to_csv 导出

【3.4 拆解指标（专业分析的核心技能！）】
  销售额 = 订单数 × 客单价

  【案例】2 月销售额最低，是不是"淡季需求少"？
    1 月：12 单 × 242.7 = 2912.2
    2 月：15 单 × 167.6 = 2513.4   ← 订单数【最多】，但客单价最低！
    3 月：13 单 × 209.5 = 2723.0
  ✅ 真相：2 月客流没减少，是【客单价下降 30.9%】
  ✅ 正确建议：提升 2 月客单价（组合套餐/满减），而不是"减少采购"

【3.5 ⚠️ 避免"过度推断"（新手最大陷阱）】
  ❌ 从 5 笔订单推出"关闭上海店铺"
  ❌ 从 3 个月波动推出"季节性规律"
  ❌ 从"销售额低"推出"该砍掉这个品类"
  ✅ 专业做法：
     · 说明【样本量】（5 单？还是 5000 单？）
     · 分清【销售额 ≠ 利润】（缺成本数据就不能断言该砍谁）
     · 区分【波动 vs 趋势】、【相关 vs 因果】
     · 用词克制："建议进一步验证"而不是"应该砍掉/关闭"

四、分析报告怎么写（交付物）
────────────────────────────────────────

【4.1 报告结构】
  一、数据概况（原始行数、清洗后行数）
  二、清洗过程（处理了哪几类问题、怎么处理的）
  三、核心发现（分维度：整体/品类/商品/时间/城市，每个结论都有数字）
  四、结论与建议（最有价值！按优先级排序）
  五、数据局限说明（专业报告必备）
  六、后续分析建议

【4.2 数据局限说明（专业度分水岭）】
  必写内容示例：
    · 样本量小：仅 40 笔订单
    · 时间跨度短：仅 3 个月，无法判断季节性
    · 缺少成本数据：只有销售额，无法计算利润
    · 数据缺失：3 笔订单城市缺失（13.3%），已标注"未知"并排除在城市分析外

【4.3 建议要写成"行动"，并标注优先级】
  ✅ "降低单品依赖（优先级：高）：樱桃占 39.8%，建议扩展高单价品类，
      将单品占比控制 20% 以内"
  ❌ "水果卖得好，多进水果"

【4.4 严谨措辞对照表】
  ❌ 应该砍掉蔬菜        → ✅ 样本不足，建议扩充品种后验证
  ❌ 2 月是淡季          → ✅ 2 月订单数最多但客单价下降 30.9%
  ❌ 关闭上海店铺        → ✅ 上海单均偏低，建议排查原因后再决策
  ❌ 销售额高就好        → ✅ 销售额高 ≠ 利润高（缺少成本数据）

六、本周避坑手册
────────────────────────────────────────
  坑 1：pd.to_datetime 遇到混合格式报 ValueError
       → 先 str.replace 统一，或加 format="mixed"
  坑 2：barh 横向柱状图的 xlabel/ylabel 写反
       → X 轴=数值，Y 轴=类别
  坑 3：饼图加了 xlabel/ylabel/grid（无效，饼图没有坐标轴）
  坑 4：子图设置写在最后 → 只作用于最后一个子图
       → 设置要写在对应 subplot 内部
  坑 5：子图忘记 savefig → 只有前几张图生成文件
  坑 6：以为类别能算相关系数
       → 分类变量只能"分组比较"，编码后算相关毫无意义
  坑 7：过度推断（从小样本推出关店/砍品类等重大决策）
  坑 8：只看销售额下结论 → 要拆解"销售额=订单数×客单价"
  坑 9：git add . 在子文件夹执行 → 只添加该子目录的改动！
       → 用 git add -A（整个仓库）或在仓库根目录执行
  坑 10：push 报 "Connection was reset"（国内网络）
       → 重试即可；或 git config --global http.version HTTP/1.1
  坑 11：忘记 git add 就 commit → "no changes added to commit"
  坑 12：PowerShell 显示中文乱码 ≠ 文件坏了（编码显示问题）

七、离线自测题（先自己答，再看答案）
────────────────────────────────────────
  Q1. 折线图/柱状图/散点图分别适合看什么？
  Q2. 画中文图表必须设哪两行？savefig 和 show 哪个在前？
  Q3. 子图里设置坐标轴旋转，应该写在哪？
  Q4. 横向柱状图 barh 的 X 轴和 Y 轴分别是什么？
  Q5. 处理缺失值时，什么时候删、什么时候填充？
  Q6. .str 和 .dt 访问器分别用来干什么？
  Q7. pd.to_datetime 遇到 "2026/1/09" 为什么报错？怎么解决？
  Q8. 为什么"类别"不能和"销量"算相关系数？
  Q9. 想知道"不同类别销量有没有差异"，该用什么方法？
  Q10. groupby 的结果怎么变回普通表格？
  Q11. 销售额 = ？× ？ 这个拆解有什么用？
  Q12. 什么是"过度推断"？举一个例子。
  Q13. 专业报告的"数据局限说明"要写什么？
  Q14. git add . 和 git add -A 有什么区别？

  【答案】
  A1. 折线图看趋势、柱状图比大小、散点图看两个变量的关系。
  A2. plt.rcParams["font.sans-serif"] = ["SimHei"] 和
      plt.rcParams["axes.unicode_minus"] = False；
      savefig 必须在 show 之前（否则存空白图）。
  A3. 写在对应子图的代码里（在 plt.subplot(...) 之后、下一个
      subplot 之前），因为 plt.xxx 只作用于当前子图。
  A4. X 轴是数值（柱子长度），Y 轴是类别名。
  A5. 关键字段（影响计算，如数量/单价）缺失 → 删除；
      非关键字段（如城市）缺失 → 填充（"未知"）。
  A6. .str 处理字符串（strip/upper/replace/contains）；
      .dt 处理日期（year/month/day/dayofweek）。
  A7. 因为列里混了不同格式（- 和 /），pandas 3.0 严格校验格式。
      解决：先用 .str.replace("/","-") 统一，或用 format="mixed"。
  A8. 类别是分类标签，没有大小顺序；相关系数只对数值变量有意义。
      编码成数字后算出来的"相关系数"取决于编号顺序，是假结论。
  A9. 用分组比较：df.groupby("类别")["销量"].agg(["count","sum","mean"])
      然后比较各类的均值差异，说"差异明显"而非"相关"。
  A10. 用 .reset_index()（把索引变回普通列）。
  A11. 销售额 = 订单数 × 客单价。它能帮你定位"销售额下降"
       到底是订单少了，还是每单买得少了——两者对策完全不同。
  A12. 用不够充分的证据下过强的结论。例：从 5 笔上海订单
       推断"应该关闭上海店铺"。
  A13. 样本量、时间跨度、缺失数据比例、缺少的字段
       （如无成本数据则不能算利润）等。
  A14. git add . 只添加"当前目录及子目录"的改动；
       git add -A 添加"整个仓库"的所有改动。
