阶段一：Python 基础（第 1-3 周）—— 已完成，但要看"深度够不够"
────────────────────────────────────────
  🔴 变量 / 数据类型 / 判断 / 循环            已掌握，够用
  🔴 输入输出 / f-string                     已掌握；f-string 在拼提示词时天天用
  🔴 列表 / 元组 / 字典 / 集合                已掌握；**字典是重点**——
                                             LLM 的请求/响应、Agent 的工具定义
                                             全是字典/JSON 结构
  🔴 字符串操作（split/join/replace/strip）   已掌握；处理模型输出全靠它
  🟡 函数 / 参数 / 返回值                     已掌握；**建议再补两块**：
                                             ① 类型注解（FastAPI/Pydantic 靠它）
                                             ② *args/**kwargs（封装 API 时用得到）
  🔴 异常处理 try/except                      已掌握，**极其重要**——
                                             API 调用失败、限流、超时全靠它兜住
  🔴 文件读写（with open）                    已掌握；读写配置/日志/知识库文档要用
                                             **建议加强：JSON 文件读写**（json 模块）
  🔴 面向对象（类/对象/方法）                 已掌握，**极其重要**——
                                             把 LLM 客户端、Agent 工具封装成类是
                                             工程化的第一步
  🔵 继承 / 多态                             了解即可，应用开发很少自己写继承体系
  🟡 os / datetime / random                  会用即可；os 处理路径、datetime 打日志
                                             random 基本用不到（LLM 场景不需要）
  🟡 迭代器 / 生成器                         会用即可；**但"流式输出"就用生成器思想**
                                             （逐块 yield 给前端）→ 值得真正弄懂
  🔴 装饰器                                  原计划写"了解概念即可"——
                                             ⚠️ **这条要升级为"会用"**：
                                             FastAPI 全是 @app.post 这种装饰器，
                                             不懂装饰器读不懂后端代码

第 6.5 周：SQL —— 🔴 必须扎实（跨岗位硬通货）
────────────────────────────────────────
  🔴 SELECT / WHERE / ORDER BY / LIMIT        已掌握（15 题全绿）
  🔴 GROUP BY / HAVING / 聚合函数              ← 必学扎实，**不只是数据岗要**
                                             理由：AI 应用里的"数据分析 Agent"、
                                             日志统计、效果评测都要写 SQL
  🔴 JOIN（INNER / LEFT）                     必学扎实，面试必问
  🔵 子查询 / 窗口函数                        了解即可——**但面试若投数据岗会考**，
                                             侧线用得上 → 建议"会写简单窗口函数"
  🔴 pandas.read_sql()                        必学——SQL 取数 → Pandas 分析 → 出图，
                                             这条链路是你"AI + 数据"组合的卖点

  📌 小结：SQL 是你**唯一一个"主线侧线都硬"的技能**，
     值得投入到最后。第 2、3 课请扎实做完。

第 7-11 周：LLM 应用开发专项 —— 🔴 全部扎实（这是主线核心）
────────────────────────────────────────
  第 1 课 LLM API 入门
    🔴 API Key 安全（.env / 绝不硬编码）      必扎实——**这是工程素养，面试会问**
    🔴 调用 API / 多轮对话 history            必扎实
    🔴 流式输出                               必扎实——用户体验关键，也是高频考点
    🟡 temperature / max_tokens 参数          会用即可，但要知道各自影响什么
    🔴 限流 / 超时 / 重试                     必扎实——生产环境必备
    🔴 产出：命令行聊天机器人                  必须做出来

  第 2 课 提示词工程 + 结构化输出
    🔴 System prompt 设计                     必扎实——**这是 LLM 应用的核心手艺**
    🔴 Few-shot 示例                          必扎实
    🔵 思维链（CoT）                          了解 + 会用在提示词里
    🔴 JSON 结构化输出                        必扎实——让模型返回可解析数据，
                                             是整个应用层的基础
    🟡 提示词评测（用 Pandas 算准确率）        会用即可，但**做了就是差异化优势**

  第 3 课 Python 工程化
    🔴 venv 虚拟环境 / requirements.txt       必扎实
    🔴 模块拆分（封装成类）                   必扎实
    🔴 .env + python-dotenv                   必扎实
    🟡 logging 日志                           会用即可，但**要养成习惯**
    🔴 异常与重试                             必扎实

  第 4 课 FastAPI 后端
    🔴 路由 / GET vs POST                     必扎实——不懂这个写不了服务
    🔴 @app.post + Pydantic 模型              必扎实
    🔴 把 LLM 封装成 /chat 接口               必扎实——**"应用"与"脚本"的分界线**
    🟡 自动文档 /docs                         会用即可（FastAPI 白送，很方便）
    🔴 产出：可被外部调用的 AI 服务            必须做出来

  第 5 课 RAG 知识库问答 ⭐
    🔴 为什么要 RAG（模型不知道私有数据）      必扎实——面试必问
    🔴 文本切分 chunking                      必扎实——切分策略直接影响效果
    🔴 Embedding 向量化                       必扎实（理解概念 + 会调用）
    🔴 向量库 chromadb                        必扎实（会增删查）
    🔴 检索 → 拼接上下文 → 生成               必扎实——RAG 主干流程
    🟡 优化（top-k / 重排序）                 会用即可，**但面试聊到会很亮眼**
    🔴 产出：用自己笔记做知识库问答            必须做出来（最有说服力的作品）

  第 6 课 Agent + 部署
    🔴 Function Calling / 工具调用            必扎实——Agent 的地基
    🟡 LangChain / LangGraph                  会用即可——**框架会用就行，
                                             面试更看重"你是否理解不靠框架怎么做"**
    🔵 MCP 概念                               了解即可（新概念，能说清是什么）
    🟡 Docker 基础                            会用即可（能打包跑起来）
    🟡 streamlit 快速界面                     会用即可
    🔴 产出：能调用工具的 Agent                必须做出来

  🔴 综合项目：2-3 个能演示的 AI 应用         必做——**这是你求职的核心资产**
  🔴 三课时的"产出物"都不能省                 这个赛道只看"能不能拿出跑起来的东西"

     为什么缺：LLM 的输入输出、日志、配置全是 JSON

     为什么缺：工程化素养，面试可能问
     现状：没有
     建议：了解即可，非必须
