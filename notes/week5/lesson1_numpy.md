# 第 5 周 · 第 1 课：NumPy —— 数值计算库

## 一、为什么需要 NumPy？（先看列表的痛点）

用列表给一堆数字每个加 5 分：
```python
scores = [92, 58, 85]
new = []
for s in scores:           # 要写循环
    new.append(s + 5)
# 或用推导式：[s + 5 for s in scores]
```

用 NumPy：
```python
import numpy as np
scores = np.array([92, 58, 85])
new = scores + 5           # ← 直接整块加！一行！
# array([97, 63, 90])
```

**核心差异**：NumPy 数组能**整块运算**（叫"向量化运算"），不用写循环，而且**快得多**（数据量大时快几十上百倍）。

## 二、创建数组

```python
import numpy as np                      # 惯例：import numpy as np

a = np.array([1, 2, 3, 4, 5])           # 从列表创建
b = np.array([1.5, 2.5, 3.5])
c = np.zeros(5)                         # [0. 0. 0. 0. 0.] 全 0
d = np.ones(3)                          # [1. 1. 1.] 全 1
e = np.arange(1, 6)                     # [1 2 3 4 5] 类似 range
f = np.arange(0, 10, 2)                 # [0 2 4 6 8] 步长 2
```

**创建二维数组**（表格/矩阵）：
```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])               # 2 行 3 列
m.shape                                 # (2, 3) 形状：2行3列
```

## 三·五、二维数组与 axis 参数（表格形态，Pandas 前奏）

### 二维数组 = 一张表（行 × 列）
```python
scores = np.array([
    [92, 85, 78],   # 第 0 行：学生1 的三门课成绩
    [58, 90, 65],   # 第 1 行：学生2
    [85, 45, 88],
])
scores.shape        # (3, 3) = 3 行 3 列
scores.size         # 9 个元素
```

### 二维索引
```python
scores[0]           # [92 85 78]  第 0 行（学生1 的全部成绩）
scores[0][1]        # 85          第 0 行第 1 列
scores[:, 0]        # [92 58 85]  所有行的第 0 列（所有人的语文）
scores[:, 1]        # [85 90 45]  所有行的第 1 列（所有人的数学）
```
**关键**：`[:, 0]` 里的 `:` 表示"**所有行**"，逗号后是"要哪一列"。

### axis 参数：往哪个方向"压扁" ⭐
```python
scores.mean(axis=1)   # 每个【学生】的平均分（压扁每一行 → 每行一个结果）
scores.mean(axis=0)   # 每门【课】的平均分（压扁每一列 → 每列一个结果）

scores.sum(axis=1)    # 每个学生的总分
scores.sum(axis=0)    # 每门课的总分
```
**记忆法**：
- `axis=1` = 横着压 → **压扁行** → 每**行**得到一个结果（按学生）
- `axis=0` = 竖着压 → **压扁列** → 每**列**得到一个结果（按科目）
- 简单记：**axis=1 管行（横向），axis=0 管列（纵向）**

### np.where：条件替换
```python
np.where(scores < 60, 0, scores)   # 小于 60 的换成 0，其余不变
np.where(scores >= 60, "及格", "不及格")   # 条件 → 分类标签
```
**用途**：数据清洗（把异常值替换掉）、打标签。

## 四、向量化运算（NumPy 最大的威力！）

```python
a = np.array([1, 2, 3, 4])

a + 10        # [11, 12, 13, 14]   每个元素 +10
a * 2         # [2, 4, 6, 8]       每个元素 ×2
a ** 2        # [1, 4, 9, 16]      每个元素平方
a / 2         # [0.5, 1., 1.5, 2.] 每个元素 ÷2
a > 2         # [False False True True]  比较也整块做！

# 两个数组之间运算（对应位置运算）：
b = np.array([10, 20, 30, 40])
a + b         # [11, 22, 33, 44]
a * b         # [10, 40, 90, 160]
```

## 五、索引和切片（和列表很像）

```python
a = np.array([10, 20, 30, 40, 50])

a[0]        # 10        第一个
a[-1]       # 50        最后一个
a[1:3]      # [20 30]   切片（含头不含尾）
a[:3]       # [10 20 30]
a[::2]      # [10 30 50] 步长 2
```

## 六、布尔索引 ⭐（数据分析最常用的操作！）

```python
scores = np.array([92, 58, 85, 45, 76])

scores >= 60              # [True False True False True]
scores[scores >= 60]      # [92 85 76]  ← 直接筛出及格的！

# 组合条件用 & (and) 和 | (or)，每个条件要加括号：
scores[(scores >= 60) & (scores < 90)]   # [85, 76]
```

**这是从数据里"挑出符合条件的东西"的标准做法**——比写循环判断简洁一万倍。

## 七、统计函数（你手写的累加/擂台套路，人家一行）

```python
scores = np.array([92, 58, 85, 45, 76])

scores.sum()      # 356      总和（你写过 3 行累加套路）
scores.mean()     # 71.2     平均值
scores.max()      # 92       最大值（你写过擂台套路）
scores.min()      # 45       最小值
scores.std()      # 标准差（衡量波动大小）
len(scores)       # 5        个数
```

**对比**：你第 2 周写的数字统计器用了 30 多行；NumPy 只要 5 行。

## 八、记忆口诀

> np.array 建数组，向量化运算不用循环；
> shape size dtype 看形状；
> 布尔索引筛数据，条件括号加 & |；
> sum mean max min，统计一行全搞定。

## 九、NumPy vs 列表：什么时候用哪个？

| 场景 | 用哪个 |
|------|--------|
| 一堆数字做数学运算 | **NumPy**（快、简洁）|
| 存不同类型的数据、增删改 | 列表 |
| 数据分析、机器学习 | **NumPy**（必备）|
| 简单的循环处理 | 列表也行 |

**结论**：搞数据/AI，NumPy 是标配——Pandas、PyTorch 底层都基于它。
