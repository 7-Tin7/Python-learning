Python 语法卡片速查表（第 1-3 周全部语法）
════════════════════════════════════════════════════════
用法：看不懂某个语法时 → 查到它 → 照着"格式模板"抄一遍
     → 写个 3 行最小例子跑一遍 → 就算打过一次照面
规则：新语法主动用满 3 次才算"认识"，7 次才算"熟"

────────────────────────────────────────
【一、基础语法（第 1 周）】
────────────────────────────────────────

▌变量赋值
  格式：名字 = 值
  例子：score = 92        name = "小明"
  记忆：= 是赋值，把右边的装进左边的盒子

▌print 输出
  格式：print(内容)
  例子：print("你好")
  记忆：显示到屏幕

▌f-string 格式化
  格式：print(f"文字{变量}文字")
  例子：print(f"{name}考了{score}分")
  记忆：f 前缀 + 大括号插变量；忘写 f 会原样打印 {name}

▌input 输入
  格式：变量 = input("提示语")
  例子：name = input("请输入姓名：")
  记忆：返回的一律是【字符串】！

▌类型转换
  格式：int(字符串) / float(字符串)
  例子：score = int(input("成绩："))
  记忆：input 出来先转换；int("abc") 会崩溃！

▌if / elif / else 分支
  格式：
    if 条件:
        代码
    elif 条件:
        代码
    else:
        代码
  例子：if score >= 60: print("及格") else: print("不及格")
  记忆：从上往下，谁先成立执行谁；else 是兜底

▌比较 / 逻辑
  格式：== != > < >= <=      and / or
  记忆：不同类型永远不相等（"1" != 1）；or 满足一个即可

▌while 循环
  格式：
    while True:
        代码
        break        # 退出循环
        continue     # 回到循环开头
  记忆：break 退出，continue 重来；退出分支必须 break！

▌for 数次数
  格式：for x in range(次数):
  例子：for x in range(3):     # 循环 3 遍
  记忆：range(3) = 0,1,2 → 循环 3 遍

▌random 随机
  格式：import random
        random.randint(a, b)       # 随机整数
        random.choice(["a","b"])   # 列表随机挑
  记忆：randint 两个数字，choice 一个列表

▌字符串检查 / 清洗
  格式："abc".isdigit()      # 是不是纯数字
        " hi ".strip()       # 去首尾空格
  记忆：isdigit 只认纯数字（85.5 不算）

────────────────────────────────────────
【二、数据结构（第 2 周）】
────────────────────────────────────────

▌列表 list
  创建：列表 = []  或  ["a", "b"]
  索引：列表[0]        # 从 0 开始！
  添加：列表.append(x)      # 末尾加
  删除：列表.remove(x)      # 按内容删（先 in 判断）
        列表.pop(索引)      # 按位置删，且返回删掉的
  数量：len(列表)
  判断：x in 列表
  遍历：for item in 列表:
  带编号：for i, item in enumerate(列表):
  记忆：方括号，索引从 0，append 加 remove 删 pop 弹

▌元组 tuple（不能改的列表）
  创建：元组 = (a, b)
  拆包：x, y = 元组        # 一次拆成两个变量
  记忆：圆括号不能改；拆包逗号连

▌集合 set（自动去重）
  创建：集合 = set()      # 空集合！不是 {}（那是字典）
        集合 = {1, 2, 3}
  添加：集合.add(x)
  运算：a & b 交集   a | b 并集
  记忆：花括号自动去重；空集必须 set()

▌字典 dict（用键找值）
  创建：d = {} 或 {"键": 值}
  取值：d["键"]
  添加/改：d["键"] = 值      # 不存在=加，存在=覆盖
  删除：del d["键"]
  判断：in 字典（查的是键）
  键列表：d.keys()   值列表：d.values()
  遍历：for k, v in d.items():
  记忆：键值对；"根据 A 找 B"用 {A: B}，A 做键！

▌字符串操作
  拆：字符串.split("分隔符")   → 列表
  拼：分隔符.join(列表)        → 字符串
  换：字符串.replace(旧, 新)   # 删除 = 换成 ""（空字符串）
  切片：字符串[开始:结束]      # 含头不含尾！
        字符串[-1]             # 最后一个
        字符串[-3:]            # 最后 3 个（有冒号=取一段）
  长度：len(字符串)
  记忆：split 拆 join 拼，replace 删换，切片含头不含尾

────────────────────────────────────────
【三、函数与文件（第 2-3 周）】
────────────────────────────────────────

▌函数 def
  格式：
    def 函数名(参数):
        代码
        return 结果        # 交货！没有 return 返回 None
  调用：结果 = 函数名(实参)
  记忆：定义不执行，调用才执行；调用 = 函数名+括号+参数
  return 交货，print 只展示！

▌异常处理
  格式：
    try:
        可能出错的代码
    except 错误类型:
        处理
    except 另一种错误类型:
        处理
  例子：except ValueError:   except ZeroDivisionError:
  记忆：一个 try 多 except，各接各的错；
        except 里处理完要 return 提前结束！
  错误信息：except X as e: print(e)

▌文件写入
  格式：
    with open("文件名", "w", encoding="utf-8") as f:
        f.write("内容\n")
  模式："w" 覆盖  "a" 追加  "r" 读取
  记忆：with 自动关；写中文要 utf-8；每条记得 \n

▌文件读取
  格式：
    with open("文件名", "r", encoding="utf-8") as f:
        for line in f:
            print(line.strip())
  记忆：for line in f 逐行读；strip 去行尾 \n

▌os 文件管理
  格式：import os
        os.path.exists("文件")    # 在不在
        os.path.getsize("文件")   # 多大
        os.remove("文件")         # 删除
  记忆：exists 查存在，getsize 看大小，remove 删文件

▌datetime 时间
  格式：from datetime import datetime
        datetime.now().strftime("%Y-%m-%d %H:%M:%S")
  记忆：%Y年 %m月 %d日 %H时 %M分 %S秒（% 在字母左边！）

────────────────────────────────────────
【四、面向对象（第 3 周）】
────────────────────────────────────────

▌类 class
  格式：
    class 类名:                      # 大驼峰
        def __init__(self, 参数):    # 造对象时自动跑
            self.属性 = 参数

        def 方法名(self):            # 方法
            代码

  造对象：对象 = 类名(参数)
  调方法：对象.方法名()
  用属性：对象.属性   方法内：self.属性
  记忆：类是模具对象是产品；先造对象再调方法（忘了报 missing self）
        方法改了哪个属性，就要护住哪个属性（设上下限）

▌主程序结构（万能骨架）
  格式：
    数据容器 = ...        # 1. 初始化
    while True:           # 2. 主循环
        显示状态          # 3. 显示
        choice = input()  # 4. 菜单
        if choice == "1": # 5. 分支
            ...
        elif ...: break   # 6. 退出分支必须 break

【五、常见报错速查（看不懂报错就查这里）】
────────────────────────────────────────
  SyntaxError          语法错误（缩进/冒号/引号写错）
  IndentationError     缩进错误（该缩没缩/多缩）
  NameError            用了没定义/不存在的变量
  TypeError            类型错误（字符串+数字、缺 self）
  ValueError           值错误（int("abc")）
  AttributeError       方法用错（字典.remove、模块没这方法）
  KeyError             字典键不存在
  IndexError           列表索引越界
  ZeroDivisionError    除以 0
  FileNotFoundError    文件不存在（读前先 exists 或 try）
  UnboundLocalError    变量没赋值就使用（except 后忘 return）
  LookupError          unknown encoding（utf-8 拼错！）
  EOFError             输入流用尽（程序还在等 input）
