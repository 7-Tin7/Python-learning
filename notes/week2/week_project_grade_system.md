# 🏫 周项目说明书：学生成绩管理系统

## 一、功能需求

1. **添加学生**：输入姓名和成绩（0~100 的整数），存入系统
   - 名字已存在 → 提示"该学生已存在"，不重复添加
2. **查看所有**：列出每个学生的姓名和成绩
3. **查找学生**：输入姓名，显示他的成绩（不存在则提示）
4. **修改成绩**：输入姓名和新成绩，覆盖旧成绩
5. **删除学生**：输入姓名，删除该学生（不存在则提示）
6. **统计成绩**：显示 平均分 / 最高分 / 最低分
7. **退出**：结束程序

## 二、数据结构设计（关键决策！）

```python
students = {}    # 姓名 → 成绩
# 例：{"小明": 92, "小红": 85, "小刚": 76}
```

**为什么用字典？** 因为系统是"**根据姓名找成绩**"——这正是字典的看家本领！
（如果要用学号找，就 `{学号: {"姓名": ..., "成绩": ...}}`——以后升级方向）

## 四、新知识点（唯一一个）：del 删除键值对

```python
students = {"小明": 92, "小红": 85}
del students["小明"]     # 删除键"小明"及其成绩
# students = {"小红": 85}
```

## 五、函数内部套路复习

| 功能 | 需要的套路 |
|------|-----------|
| 添加/修改 | `students[name] = score`（键不存在=添加，存在=覆盖）|
| 查找/删除前 | `if name in students:` 判断 |
| 查看所有 | `for name, score in students.items():` |
| 平均分 | **累加套路**：total = 0; for 循环累加; total / len |
| 最高/最低 | **擂台套路**：先假设第一个最大/最小，逐个比较 |

## 六、输入验证（沿用老套路）

成绩必须是 **0~100 的整数**：
```python
score_str = input("请输入成绩：")
if not score_str.isdigit():        # 不是数字
    print("成绩必须是数字！")
    return                         # ← 函数里用 return 提前结束
score = int(score_str)
if score < 0 or score > 100:       # 超出范围
    print("成绩必须在 0~100 之间！")
    return
```

**新技巧**：函数里 `return` 可以**提前结束函数**——验证不通过就 return，后面的代码不执行。
