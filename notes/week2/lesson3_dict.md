# 第 2 周 · 第 3 课：字典（Dict）—— 用"名字"找东西

## 一、什么是字典
- 用**花括号** `{}` 存数据，里面是"键 : 值"对（key: value）
- **用"键"（名字）找"值"（内容）**，而不是像列表那样用序号找

```python
# 列表：用序号找
names = ["小明", "小红", "小刚"]
names[0]          # "小明"（第 0 个）

# 字典：用名字（键）找
phonebook = {"小明": "13800000001", "小红": "13900000002"}
phonebook["小明"] # "13800000001"（键叫"小明"的那个）
```

## 二、基本操作

| 操作 | 写法 | 说明 |
|------|------|------|
| 创建空字典 | `d = {}` | ⚠️ 不是空集合！空集合是 `set()` |
| 取值 | `d["键"]` | 键不存在会报错 KeyError |
| 添加/修改 | `d["键"] = 值` | 键不存在=添加，存在=覆盖 |
| 判断键在不在 | `"键" in d` | 返回 True/False |
| 长度 | `len(d)` | 有几个键值对 |

```python
d = {}
d["苹果"] = 5        # 添加：苹果 → 5
d["苹果"] = 8        # 修改：覆盖成 8
d["香蕉"] = 3        # 再添加一个
len(d)               # 2
"苹果" in d          # True
"西瓜" in d          # False
```

## 三、三个遍历方法（重要！）

```python
d = {"小明": 18, "小红": 19}

d.keys()              # 所有键：["小明", "小红"]（视图）
d.values()            # 所有值：[18, 19]
d.items()             # 所有键值对：[("小明", 18), ("小红", 19)]

# 最常用：items() + 拆包（又是元组拆包！）
for name, age in d.items():
    print(f"{name}今年{age}岁")
```

## 三·五、什么时候要加 items()？（灵魂拷问）

**看容器里每个元素是"一个东西"还是"一对东西"：**

- **列表**每个元素是**一个值** → 直接 `for x in 列表` 就拿到东西，不需要任何方法
- **字典**每个元素是**一对（键, 值）** → 直接遍历**只给键**；键值都要必须 `items()`

```python
storage = ["非洲之心", "海洋之泪"]
for x in storage:      # ✅ 元素是单个物品，直接拿

contacts = {"小明": 18, "小红": 19}
for x in contacts:     # ⚠️ 只拿到键：小明、小红
for x in contacts.items():  # ✅ 拿到键值对：('小明', 18)、('小红', 19)
for k, v in contacts.items():  # ✅ 拆包：k=键, v=值
```

**判断标准**：我要的东西，是容器里的"一个整体"（列表→直接遍历），
还是"一对中的一部分"（字典→必须指明 items / values / keys）。

## 四、列表 vs 字典

| | 列表 list | 字典 dict |
|--|----------|----------|
| 符号 | `[]` | `{}` |
| 找东西用 | 序号 `[0]` | 键 `["小明"]` |
| 顺序 | 有顺序 | 无顺序（3.7+ 按插入序） |
| 适用 | 一堆同类型的东西 | 一组"名字→内容"的对应关系 |

## 五、实战威力：仓库项目重构

```python
    property = property + heart

    property = property + sea_tear
```

```python
property = property + price[new_goods]
```

## 六、记忆口诀

> 字典花括号，键值成对坐；
> 取值用中括号，键名写里面；
> 判断用 in，遍历 items；
> 添加即赋值，存在就覆盖。
