# 第 2 周 · 第 2 课：元组（Tuple）和集合（Set）

## 一、元组（Tuple）—— 不能修改的列表

### 1. 长什么样
- 用**圆括号** `()`，逗号分隔
- 用法和列表几乎一样：能索引、能 for 遍历、能 len()

```python
point = (3, 5)          # 一个坐标点
color = (255, 0, 0)     # 一个颜色
person = ("小明", 18)    # 一个"名字+年龄"组合
```

### 2. 和列表最大的区别：不可修改！
```python
point[0] = 9    # ❌ 报错！元组不能改
color.append(1) # ❌ 报错！没有 append

nums = [1, 2, 3]
nums[0] = 9     # ✅ 列表可以改
```

### 3. 元组拆包（unpacking）—— 你已经见过！
```python
person = ("小明", 18)
name, age = person      # 一次拆成两个变量！
# name = "小明", age = 18
```

`enumerate` 的原理就是元组：`for i, item in enumerate(列表)` 里
`enumerate` 每次给 `(i, item)`，for 循环帮你拆包。

### 4. 什么时候用元组？
- 一组**固定不变**的数据（坐标、日期、配置）
- 需要"打包"几个东西时（比如一个好友的名字+年龄）

## 二、集合（Set）—— 自动去重的列表

### 1. 长什么样
- 用**花括号** `{}`，逗号分隔
- ⚠️ 注意：`{}` 是空**字典**！空集合必须写 `set()`

```python
nums = {1, 2, 2, 3, 3, 3}
# 实际存储：{1, 2, 3} ← 自动去重！
```

### 2. 三大特性
| 特性 | 说明 |
|------|------|
| **自动去重** | 重复元素只保留一个 |
| **无序** | 没有顺序，不能用索引（没有 nums[0]）|
| **元素必须"可哈希"** | 数字、字符串可以；列表不行 |

### 3. 常用操作
```python
s = set()            # 空集合（不能用 {}！）
s.add("苹果")        # 添加（注意是 add，不是 append）
s.add("苹果")        # 再加一次 → 不会重复
"苹果" in s          # True
len(s)               # 1
s.remove("苹果")     # 删除

a = {1, 2, 3}
b = {2, 3, 4}
a & b   # {2, 3}         交集（两边都有）
a | b   # {1, 2, 3, 4}   并集（合起来）
a - b   # {1}            差集（a 有 b 没有）
```

### 4. 什么时候用集合？
- **去重**：一堆数据里想快速知道"有哪些不同的"
- **快速判断存在**：`x in 集合` 比 `x in 列表` 快得多（大数据时）

## 三、记忆口诀

> 元组圆括号，生来不能改；
> 集合花括号，自动去重来；
> 空集用 set()，空字典是 {}；
> 拆包逗号连，for 里最常见。
