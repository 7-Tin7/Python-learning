# 第 2 周 · 第 4 课：字符串操作（join 的兄弟们）

> 你已经会 `join`（列表 → 字符串），这课补齐它的另一半世界。

## 一、split() —— join 的反操作（字符串 → 列表）

```python
", ".join(["a", "b"])   # 列表 → 字符串："a, b"
"a,b,c".split(",")      # 字符串 → 列表：['a', 'b', 'c']
```

- `split(分隔符)`：按分隔符把字符串拆成列表
- 不写分隔符 = 默认按**空格**拆（连续空格也自动合并）

```python
"苹果,香蕉,橘子".split(",")     # ['苹果', '香蕉', '橘子']
"hello world python".split()    # ['hello', 'world', 'python']
"138-1234-5678".split("-")      # ['138', '1234', '5678']
```

**💡 仓库项目彩蛋**：还记得最早的 game_goods 是字符串"非洲之心,海洋之泪,..."吗？
现在一行就能转成列表：`game_goods = "非洲之心,海洋之泪".split(",")`

## 二、切片 [start:end] —— 截取子串

```python
s = "Python编程"
s[0]      # 'P'            第一个字符
s[0:3]    # 'Pyt'          第 0~2 个（⚠️ 结束位置不含）
s[1:]     # 'ython编程'     从第 1 个到结尾
s[:3]     # 'Pyt'          前 3 个
s[-1]     # '程'           最后一个字符（负数从右数）
s[-4:]    # 'on编程'        最后 4 个
```

**要点**：
- `[开始:结束]`，**含头不含尾**（结束位置不包含）
- 负数从右边数：`-1` 是最后一个
- 省略开始 = 从头；省略结束 = 到尾巴

## 三、replace(old, new) —— 替换

```python
"hello world".replace("world", "python")   # 'hello python'
"2024-01-01".replace("-", "/")             # '2024/01/01'
```

## 四、其他常用小工具

```python
"  hello  ".strip()        # 'hello'            去首尾空格（你用过！）
"abc".upper()              # 'ABC'              转大写
"ABC".lower()              # 'abc'              转小写
len("hello")               # 5                  字符串长度
"world" in "hello world"   # True               子串判断（和列表 in 一样）
```

## 五、对比全家桶

| 操作 | 方向 | 例子 |
|------|------|------|
| `join` | 列表 → 字符串 | `",".join(["a","b"])` |
| `split` | 字符串 → 列表 | `"a,b".split(",")` |
| 切片 | 字符串 → 子串 | `"abcde"[1:3]` |
| `replace` | 字符串 → 新字符串 | `"abc".replace("a","x")` |

## 六、记忆口诀

> join 拼列表，split 拆字符串；
> 切片含头不含尾，负一就是最后面；
> replace 换新词，strip 去两边。
