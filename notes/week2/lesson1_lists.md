# 第 2 周 · 第 1 课：列表（List）

## 1. 什么是列表
- 一个能装多个东西的"盒子"，用方括号 `[]`，逗号分隔
- 可以装字符串、数字，也可以混着装，还可以是空列表

```python
fruits = ["苹果", "香蕉", "橘子"]
numbers = [1, 2, 3, 4, 5]
empty = []
```

## 2. 索引（从 0 开始！）
- `fruits[0]` → "苹果"（第 1 个元素的编号是 0）
- `fruits[1]` → "香蕉"
- 编号从 0 开始，这是初学者最常踩的坑

## 3. 常用方法
| 方法 | 作用 | 示例 |
|------|------|------|
| `append(x)` | 末尾添加 x | `fruits.append("西瓜")` |
| `remove(x)` | 删除 x | `fruits.remove("香蕉")` |
| `len(列表)` | 列表有几个元素 | `len(fruits)` → 3 |
| `x in 列表` | x 在不在列表里 | `"苹果" in fruits` → True |

## 4. for 循环遍历
```python
for f in fruits:
    print(f)
```
- `for x in 列表:` 把每个元素依次取出来，存进变量 x
- 遍历列表的标配写法

## 5. 记忆口诀
> 列表方括号，索引零开头；
> 添加 append，删除 remove；
> 长度用 len，遍历 for 走。
