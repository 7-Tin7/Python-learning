一、NumPy 核心知识
────────────────────────────────────────

【1.1 为什么需要 NumPy？】
  列表给每个数字 +5：
    new = [s + 5 for s in scores]      # 要写推导式/循环
  NumPy：
    scores = np.array([92, 58, 85])
    new = scores + 5                   # 整块运算！一行！
  这叫【向量化运算】——不用循环，而且快几十倍（底层用 C 实现）。

【1.2 创建数组】
  import numpy as np                    # 惯例简写 np
  a = np.array([1, 2, 3, 4, 5])
  np.zeros(5)                           # [0. 0. 0. 0. 0.]
  np.ones(3)                            # [1. 1. 1.]
  np.arange(1, 6)                       # [1 2 3 4 5]
  np.arange(0, 10, 2)                   # [0 2 4 6 8]

【1.3 数组属性（三个"数"别搞混！）】
  a = np.array([1, 2, 3, 4, 5])
  a.shape      # (5,)      形状
  a.size       # 5         元素个数
  a.dtype      # int64     数据类型
  len(a)       # 5         长度（一维时等于 size）

  ⚠️ 二维数组时：
    scores.shape      # (5, 3)  5行3列
    scores.size       # 15      总元素个数
    len(scores)       # 5       只是【行数】！不是总个数
    scores.sum()      # 1189    所有元素的和（是个数字，不能 len()！）

【1.4 向量化运算】
  a + 10       # 每个 +10
  a * 2        # 每个 ×2
  a ** 2       # 每个平方
  a > 2        # [False False True True] 比较也整块做
  a + b        # 两个数组对应位置相加

【1.5 索引与切片（和列表类似）】
  a[0]        # 第一个
  a[-1]       # 最后一个
  a[1:3]      # 切片（含头不含尾）
  a[::2]      # 步长 2

【1.6 布尔索引 ⭐ 数据分析最常用！】
  scores = np.array([92, 58, 85, 45, 76])
  scores[scores >= 60]                     # [92 85 76] 直接筛出及格的
  scores[(scores >= 60) & (scores < 90)]   # 组合条件，每个都要加括号
  np.sum(scores < 60)                      # 数有多少个 True = 个数！(技巧)

【1.7 统计函数（手写套路 → 一行）】
  scores.sum()      # 总和（以前写 3 行累加套路）
  scores.mean()     # 平均
  scores.max()      # 最大（以前写擂台套路）
  scores.min()      # 最小
  scores.std()      # 标准差

【1.8 二维数组与 axis 参数 ⭐（最容易混的点）】
  二维数组 = 一张表（行 × 列）：
    scores = np.array([
        [92, 85, 78],   # 第 0 行 = 学生1 的三门课
        [58, 90, 65],   # 第 1 行 = 学生2
    ])
    scores.shape        # (2, 3) = 2行3列

  取行 / 取列：
    scores[0]           # [92 85 78]  第 0 行（学生1）
    scores[:, 0]        # [92 58]     所有行的第 0 列（所有人的语文）
    （: 表示"所有行"，逗号后是要哪一列）

  axis 参数（往哪个方向"压扁"）：
    scores.mean(axis=1)   # 每个【学生】的平均分（压扁行 → 每行一个结果）
    scores.mean(axis=0)   # 每门【课】的平均分（压扁列 → 每列一个结果）
    scores.sum(axis=1)    # 每个学生的总分
    scores.sum(axis=0)    # 每门课的总分

  记忆法：axis=1 横着压（管行），axis=0 竖着压（管列）

【1.9 np.where：条件替换】
  np.where(scores < 60, 0, scores)          # 小于60的换成0
  np.where(scores >= 60, "及格", "不及格")   # 打标签
  读法：where(条件, 满足时用什么, 不满足时用什么)

二、Pandas 核心知识
────────────────────────────────────────

【2.1 Pandas 是什么？】
  Excel 的 Python 版，处理有【列名】的表格数据。
  和 NumPy 的关键区别：
    scores[:, 0]        # NumPy：用位置（第0列是啥？要记）
    df["价格"]          # Pandas：用列名（一眼就懂！）

  两个核心对象：
    DataFrame = 一张表（多列）
    Series    = 一列

【2.2 读取文件（真实数据入口）】
  import pandas as pd
  df = pd.read_csv("商品数据.csv", encoding="utf-8")
  df = pd.read_excel("数据.xlsx")        # 需要 openpyxl

【2.3 侦察数据（先看长什么样）】
  df.head()        # 前 5 行（最常用）
  df.head(3)       # 前 3 行
  df.tail()        # 后 5 行
  df.shape         # (15, 5) 多少行多少列
  df.columns       # 所有列名
  df.info()        # 每列类型 + 有无缺失值
  df.describe()    # 数值列统计摘要

  ⚠️ df.info() 是"自己打印"，没有返回值：
     放进 f-string 会显示 None！
     正确：单独一行调用 df.info()

【2.4 选列】
  df["价格"]                 # 选一列 → Series
  df[["商品名称", "价格"]]    # 选多列 → DataFrame（双层括号！）

【2.5 筛选（布尔索引，用列名）】
  df[df["价格"] > 10]                          # 价格大于10
  df[df["类别"] == "水果"]                      # 类别是水果
  df[(df["价格"] > 10) & (df["类别"] == "水果")]  # 组合条件（括号 + &）

【2.6 统计】
  df["价格"].mean()      # 平均价格
  df["价格"].max()       # 最贵
  df["销量"].sum()       # 总销量
  df["价格"].describe()  # 一揽子统计

【2.7 排序】
  df.sort_values("价格")                          # 升序
  df.sort_values("价格", ascending=False)          # 降序
  df.sort_values("销量", ascending=False).head(3)  # 前3名

【2.8 新增列（真的会修改 df！）】
  df["销售额"] = df["价格"] * df["销量"]     # 整列向量化计算
  df["是否高价"] = df["价格"] > 20            # 生成 True/False 列
  ⚠️ 这行执行后，df 就多了一列——后面 to_csv 会把它一起存出去！

【2.9 分组统计 groupby ⭐（Pandas 最强功能）】
  df.groupby("类别")["价格"].mean()     # 每个类别的平均价
  df.groupby("类别")["销量"].sum()      # 每个类别的总销量
  df.groupby("类别").size()             # 每个类别有几个商品
  读法：按什么分组[对哪列统计].怎么统计()
  意义：从"明细"提炼"分类汇总"——这就是"分析"的核心动作

【2.10 保存结果】
  df.to_csv("分析结果.csv", encoding="utf-8-sig", index=False)
  # index=False → 不保存自动生成的行号列
  # utf-8-sig  → Excel 打开中文不乱码

  【重要理解】to_csv 保存的是"此刻 df 的全部内容"！
    包括：原始所有列 + 你新增的列
    不包括：只 print 出来、没存进变量的中间结果（比如 groupby 结果）
    想存分组结果 → 先接住：result = df.groupby(...).mean()
                          result.to_csv(...)

【2.11 数据流全景】
  商品数据.csv（原始5列）
      ↓ read_csv
  df（内存中的表格）
      ↓ df["销售额"] = ...   ← 加了一列（df 被修改）
  df（现在6列）
      ↓ to_csv
  分析结果.csv（6列）← 原始数据 + 新增列

  import numpy as np

四、避坑手册（第 5 周）
────────────────────────────────────────
  坑 1：for p in prices → p 是【键】不是值（老坑第 4 次出现！）
       → 要值用 .values()，要键值用 .items()
  坑 2：浮点数尾巴 3.5*0.8 = 2.8000000000000003
       → 用 round(结果, 2)；凡涉及"钱"都要 round
  坑 3：len(scores.sum()) → TypeError（数字没有长度）
       → 要总个数用 scores.size
  坑 4：len(二维数组) 只数【行数】
       → 总元素个数用 .size
  坑 5：np.where 算了却没 print → 屏幕上什么都没有
       → 结果要先接住再打印：fixed = np.where(...)
  坑 6：CSV 文件名写错（商品数据_csv vs 商品数据.csv）
       → FileNotFoundError。文件名必须一字不差！
  坑 7：文件路径/工作目录不对 → 找不到文件
       → cd 到文件所在目录，或写完整路径加 r""
       → 排查神器：print(os.getcwd())
  坑 8：中文文件编码 → 读用 encoding="utf-8"
       → 写 CSV 用 "utf-8-sig"（Excel 打开不乱码）
  坑 9：df.info() 放进 f-string → 输出多个 None
       → 单独一行调用
  坑 10：选多列只写一层括号 df["a","b"] ❌
       → 要双层 df[["a","b"]]
  坑 11：组合条件忘了括号 → 报错
       → 每个条件加括号 + 用 & ：df[(df["价格"]>10) & (df["类别"]=="水果")]
  坑 12：以为 groupby 的结果被保存了
       → 没存进变量的结果只存在屏幕上一瞬间

五、离线自测题（先自己答，再看答案）
────────────────────────────────────────
  Q1. NumPy 数组和列表的最大区别是什么？
  Q2. scores + 5 做了什么？为什么不用写循环？
  Q3. 布尔索引 scores[scores >= 60] 返回什么？
  Q4. 二维数组的 shape 是 (5, 3)，mean(axis=1) 得到几个值？
  Q5. axis=0 和 axis=1 分别"压扁"什么方向？
  Q6. .size 和 len() 在二维数组上有什么区别？
  Q7. Pandas 里怎么选"价格"这一列？怎么选多列？
  Q8. df[df["价格"] > 10] 是什么意思？
  Q9. groupby("类别")["价格"].mean() 的结果是什么？
  Q10. df.to_csv 保存的是哪些内容？groupby 结果会被保存吗？
  Q11. 读中文 CSV 用什么编码？写 CSV 用什么编码？
  Q12. 3.5 * 0.8 为什么会出现长尾巴？怎么处理？

  【答案】
  A1. NumPy 数组能【整块运算】（向量化），不用写循环，
      且运算速度快得多（底层 C 实现）；列表只能逐个处理。
  A2. 给数组里【每个元素】都加 5。因为 NumPy 支持向量化运算，
      一个表达式就作用到整个数组。
  A3. 一个只包含满足条件元素的新数组（这里筛出 >= 60 的成绩）。
  A4. 5 个值（每行一个结果，对应每个学生）。
  A5. axis=1 横着压（压扁行，得到每行一个结果）；
      axis=0 竖着压（压扁列，得到每列一个结果）。
  A6. .size 是总元素个数（5×3=15）；
      len() 只数第一维（行数 5）。
  A7. 选一列：df["价格"]；选多列：df[["商品名称", "价格"]]（双层括号）。
  A8. 筛选出"价格"这一列大于 10 的所有行（布尔索引）。
  A9. 每个类别（水果/蔬菜/零食/饮料）的平均价格（一个 Series）。
  A10. 保存此刻 df 的全部内容（原始列 + 新增的列，如销售额）。
       groupby 的结果如果没存进变量，不会被保存。
  A11. 读用 encoding="utf-8"；写用 "utf-8-sig"（防 Excel 乱码）。
  A12. 二进制无法精确表示 0.8，只能存近似值。
       用 round(结果, 2) 四舍五入。

六、本周口诀
