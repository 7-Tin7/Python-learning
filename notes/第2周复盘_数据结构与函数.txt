一、核心知识理论精讲（本周重点！）
────────────────────────────────────────

【1.1 列表 list —— 能改的一堆东西】
  符号：[ ]，用逗号分隔
  fruits = ["苹果", "香蕉", "橘子"]
  - 索引从 0 开始！fruits[0] = "苹果"
  - 常用方法：
      append(x)     末尾添加
      remove(x)     删除指定项（不存在会崩溃！先 in 判断）
      len(列表)     元素个数
      x in 列表     x 在不在列表里
  - 遍历：for item in 列表
  - 带编号遍历：for i, item in enumerate(列表)  # i 从 0 开始
  - 列表能改：fruits[0] = "西瓜"  # 可以！
  应用：购物清单、仓库、一切"一堆东西"

【1.2 元组 tuple —— 不能改的列表】
  符号：( )
  point = (3, 5)          # 坐标
  - 和列表几乎一样，唯一区别：不可修改！
      point[0] = 9   # 报错！
  - 用途：固定不变的一组数据；打包几个相关的值
  - 拆包（unpacking）：一次拆成多个变量
      name, age = ("小明", 18)    # name="小明", age=18
  - enumerate 的秘密：for i, item in enumerate(...) 里
    enumerate 给的就是 (编号, 元素) 元组，i, item 就是拆包！
  - items() 的键值对也是元组：for k, v in 字典.items()

【1.3 集合 set —— 自动去重的列表】
  符号：{ }（注意：{} 是空【字典】，空集合必须 set()！）
  nums = {1, 2, 2, 3}     # 实际是 {1, 2, 3} 自动去重
  - 特性：去重、无序（不能用 nums[0]！）
  - 添加用 add()（不是 append！）
  - 独门绝技：交集 &、并集 |、差集 -
      a = {1,2,3}; b = {2,3,4}
      a & b → {2,3}     a | b → {1,2,3,4}
  - 应用：统计"有几种不同的XX"（好友年龄统计器）

【1.4 字典 dict —— 用"名字"找东西（本周重头戏）】
  符号：{键: 值}
  contacts = {"小明": "138...", "小红": "139..."}
  - 列表用序号找 [0]，字典用键找 ["小明"]
  - 基本操作：
      d = {}                  # 空字典
      d["苹果"] = 5           # 添加（键不存在=添加）
      d["苹果"] = 8           # 修改（键存在=覆盖！同一行代码）
      d["苹果"]               # 取值（键不存在报 KeyError！）
      "苹果" in d             # True 判断键在不在
      len(d)                  # 键值对个数
      del d["苹果"]           # 删除键值对（字典没有 remove！）
  - 三个遍历方法：
      for k in d:             # 只拿键（直接遍历字典 = 只给键！）
      for v in d.values():    # 只拿值
      for k, v in d.items():  # 键值都拿（最常用）
  - 灵魂拷问"什么时候加 items()"：
      列表元素是"一个东西"→ 直接遍历
      字典元素是"一对(键,值)"→ 直接遍历只给键，
      键值都要必须 .items()
  - 应用判断：只要"根据 A 找 B"→ 就用字典 {A: B}，
    被找的那个(A)做键！例：号码→姓名，{号码: 姓名}；
    姓名→成绩，{姓名: 成绩}
  - 字典键不能重复 → 自动防重

【1.5 字符串操作 —— 文字的加工工具】
  join：列表 → 字符串      ",".join(["a","b"]) → "a,b"
  split：字符串 → 列表      "a,b,c".split(",") → ['a','b','c']
       （split() 不写参数 = 按空格拆）
  replace：替换/删除        "abc".replace("a","x") → "xbc"
       删除 = replace(旧, "")  ← 空字符串！
       替换成" "空格 ≠ 删除！空格也是字符！
  strip：去首尾空格         "  hi  ".strip() → "hi"
  切片：截取一段            s[开始:结束]
       铁律：【含头不含尾】s[0:3] 取第 0、1、2 个
       负数从右数：s[-1] 最后一个
       s[-3]（没冒号）= 一个字符；s[-3:]（有冒号）= 最后 3 个字符
       冒号在 = 取一段；没冒号 = 取一个！
  len(字符串) = 字符个数     "abc" in "xxabcxx" = True(子串)
  isdigit()：是不是纯数字（整数）

【1.6 函数 def —— 把代码打包】
  为什么：消除重复代码（比如"显示资产"在两处重复）
  三步走：
    定义 def 函数名(参数):    # 定义不执行！只是写菜谱
        函数体
    调用 函数名(实参)          # 调用才执行！函数名+括号
    返回 return 结果           # 把结果交给调用者
  return vs print 的区别：
    return 100  → x = f() 后 x = 100（交货）
    print(100)  → x = f() 后 x = None（只展示，交白卷！）
  形参 vs 实参：
    def add(a, b) 里的 a,b 是形参（收件箱）
    add(x, y) 调用时把实参 x,y 的值【按位置】投给形参
    定义和调用的变量名不需要一样！位置对上就行
  记忆：
    return = 交货（能存变量）
    print = 展示（只显示）
    函数名没括号 = 函数本身（打印出来是 <function ...> 内存地址）
    调用 = 函数名 + 括号 + 参数

【1.7 range —— 数次数工具】
  range(3)    → 0,1,2（循环 3 遍）
  range(1,4)  → 1,2,3
  range(0,10,2) → 0,2,4,6,8（步长 2）
  应用：for x in range(3): 录入 3 次

【1.8 累加套路 & 擂台套路（写算法必备）】
  累加套路（求和/平均/计数）：
      total = 0
      for x in 一堆数:
          total = total + x
  擂台套路（找最大/最小）：
      biggest = 列表[0]       # 先假设第一个是擂主
      for x in 列表:
          if x > biggest:     # 挑战者赢了才换擂主
              biggest = x
      # 循环结束后 biggest 就是冠军 → 循环外才打印！
  注意：擂台要在循环【结束后】宣布结果，循环里只更新变量

【1.9 输入验证标准模板（三/四道关卡）】
  x = input(...)                    # 先拿字符串
  if x == "q": break                # ① 退出判断
  if not x.isdigit(): continue      # ② 数字检查
  num = int(x)                      # ③ 安全后才转换
  if num > 100 or num < 0: continue # ④ 范围检查
  # 全部通过才进行业务处理
  铁律：【先检查，后转换】——int() 之前必须 isdigit 确认！
  反面教材：score = int(input()) 后再检查 = 输入 abc 直接崩溃

三、避坑手册（第 2 周所有坑，一条一条背）
────────────────────────────────────────
  坑 1：用了上次残留的变量（name）而不是新输入（student/name1）
       → 显示错人/崩溃（NameError）
       → 口诀：新输入的值，用新变量！
  坑 2：字典用了 .remove() / .append()
       → 崩溃（AttributeError）——remove 是列表的，字典用 del
       → 口诀：删字典用 del d[键]
  坑 3：for score, name in contacts.items() 顺序写反
       → items() 给 (键,值)，第一个变量永远是键！
       → 口诀：名字要对上内容（键=姓名就写 name 在前）
  坑 4：成绩存成字符串就运算
       → "92" > "100" 按字典序比较 → 结果错乱
       → 口诀：input 先转换，再存再算
  坑 5：contacts[0] 字典用序号索引
       → 崩溃（KeyError）——字典没有顺序！
       → 口诀：取全部值用 values()
  坑 6：int() 在检查之前执行
       → 输入 abc 直接崩溃（ValueError）
       → 口诀：先检查(isdigit)后转换(int)！检查放 int 之前！
  坑 7：sentence[-3] 写成没冒号
       → 只取 1 个字符，不是最后 3 个
       → 口诀：有冒号=取一段，没冒号=取一个
  坑 8：replace("-", " ") 用空格替换
       → 空格也是字符，长度不变！要删就用空字符串 ""
       → 口诀：删除 = 替换成 ''（空字符串），不是 ' '（空格）
  坑 9：验证写成"马后炮"（检查放在会出错的操作之后）
       → 等于没检查
       → 口诀：检查必须发生在可能出错的操作【之前】
  坑 10：函数里 print 不 return
       → 调用结果永远是 None
       → 口诀：return 交货，print 只展示

四、万能决策表（看到需求选数据结构）
────────────────────────────────────────
  需求                            → 选择
  一堆同类型、要增删改            → 列表 list
  一组固定不变的数据              → 元组 tuple
  一堆数据要自动去重/求交集       → 集合 set
  根据 A 找 B（名字找成绩...）    → 字典 dict {A: B}
  要把列表变成字符串              → join
  要把字符串按分隔符拆开          → split
  要截取字符串的一部分            → 切片 [开始:结束]
  重复使用的代码块                → 函数 def

五、离线自测题（先自己答，再看答案）
────────────────────────────────────────
  Q1. 列表和元组的根本区别？各举一个用途。
  Q2. 为什么空集合必须写 set() 而不是 {}？
  Q3. 字典为什么用"号码"做键而不是姓名（通讯录场景）？
  Q4. for x in 字典 拿到的是什么？想要键和值怎么办？
  Q5. 字符串切片 [0:3] 包含第几个字符？为什么不包含第 3 个？
  Q6. return 和 print 在函数里的区别？
  Q7. 输入验证的正确顺序是什么？为什么？
  Q8. 删除字典里的键值对用什么？删除字符串里的字符用什么？
  Q9. 累加套路和擂台套路的共同点？
  Q10. 学生成绩系统为什么用字典？用列表行不行（缺点）？
  Q11. 用户输入了 "abc"，你直接 int(input()) 会怎样？怎么避免？
  Q12. enumerate 和 items() 分别返回什么？（提示：都是元组）

  【答案】
  A1. 元组不可修改，列表可改。
      元组：坐标(3,5)、打包 (name,age)；列表：购物清单、仓库。
  A2. {} 是空字典；{} 和 set() 是两个不同容器。
  A3. 因为查找需求是"给号码找姓名"——被找的(A)做键，
      字典规则是"用键找值"。姓名做键只能"用姓名找号码"。
  A4. 只拿到键(key)。键值都要用 for k, v in d.items()。
  A5. 取第 0、1、2 个字符，共 3 个。"含头不含尾"——
      结束位置不包含，这是 Python 切片的规定。
  A6. return 把结果交给调用者（能存进变量）；print 只是显示，
      函数没有 return 时返回值是 None。
  A7. 先字符串检查(isdigit) → 再 int() 转换 → 再范围检查。
      因为 int() 遇到非数字会直接崩溃，检查必须放在转换之前。
  A8. 删字典键值对用 del d[键]；删字符串字符用 replace(旧, "")。
  A9. 都是"先初始化一个变量，再 for 循环逐个更新，循环结束后
      变量就是最终结果"——循环外使用结果。
  A10. 需求是"根据姓名找成绩"，字典一步到位。
      用列表要遍历查找，还要保证姓名唯一，麻烦且易错。
  A11. int("abc") 崩溃(ValueError)。避免：先 if not x.isdigit()
      检查，通过了再 int()。
  A12. enumerate(列表) 返回 (编号, 元素)；字典.items()
      返回 (键, 值)。都是元组，都能拆包成两个变量。

六、两周口诀大汇总
────────────────────────────────────────
  列表方括号，索引零开头；
  元组圆括号，生来不能改；
  集合花括号，自动去重来（空集 set()，空字典是 {}）；
  字典键值对，用键来查找；
  join 拼列表，split 拆字符串；
  切片含头不含尾，负一就是最后面；
  def 定函数，return 交货 print 展示；
  先检查后转换，isdigit 保平安；
  新输入用新变量，删字典用 del；
  累加算总和，擂台找最大；
  万能骨架循环转，数据容器先选好。
