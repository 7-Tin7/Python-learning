# 🎮 Git 实操练习（照着敲，一步步来）

> 目标：在 15 分钟内体验 Git 的"存档 + 读档"。
> 建议在 PyCharm 的 Terminal 里跟着敲（或 CMD/PowerShell）。

════════════════════════════════════
第 0 步：准备练习文件夹
════════════════════════════════════
新建一个文件夹，比如 D:\git练习，然后在终端进入它：

  cd D:\git练习

════════════════════════════════════
第 1 步：初始化仓库（只做一次）
════════════════════════════════════
  git init

✅ 成功标志：出现
  Initialized empty Git repository in .../git练习/.git/

（文件夹里会多出一个隐藏的 .git 文件夹 = 你的存档库）

════════════════════════════════════
第 2 步：创建第一个文件
════════════════════════════════════
在文件夹里新建 hello.py，写入：

  print("你好，Git！")

════════════════════════════════════
第 3 步：看看 Git 什么反应
════════════════════════════════════
  git status

📖 你会看到 hello.py 显示为【红色】：
  Untracked files: hello.py
  意思：Git 发现了新文件，但还没"跟踪"它

════════════════════════════════════
第 4 步：把文件加入暂存区
════════════════════════════════════
  git add .
  git status

📖 现在 hello.py 变成【绿色】：
  Changes to be committed: new file: hello.py
  意思：已放进"书包"，准备存档

════════════════════════════════════
第 5 步：存档！（第一次提交）
════════════════════════════════════
  git commit -m "第一次提交：添加 hello.py"

✅ 成功标志：出现 1 file changed, 1 insertion(+)

════════════════════════════════════
第 6 步：修改文件，再存一次档
════════════════════════════════════
把 hello.py 改成：

  print("你好，Git！")
  print("我正在学习版本控制！")

然后：

  git status
  git add .
  git commit -m "添加第二行问候语"

════════════════════════════════════
第 7 步：查看历史存档
════════════════════════════════════
  git log --oneline

📖 你会看到两条记录（最新的在最上面）：
  f3a9c21 添加第二行问候语
  a1b2c3d 第一次提交：添加 hello.py

════════════════════════════════════
第 8 步：体验时光机（撤销未提交的改动）
════════════════════════════════════
故意把 hello.py 改坏（比如删掉所有内容，随便乱写），然后：

  git restore hello.py

✅ 文件瞬间恢复成上次提交的样子！——这就是"读档"。

════════════════════════════════════
第 9 步（选做）：回退到历史版本
════════════════════════════════════
  git log --oneline                  # 找到第一条的存档号
  git reset --hard 存档号            # 回到那个版本

（⚠️ 这会丢弃之后的改动，想清楚再用）

════════════════════════════════════
✅ 完成检查清单
════════════════════════════════════
  [ ] git init 成功
  [ ] git status 看到红→绿的变化
  [ ] 提交了两次（git log 有两条）
  [ ] git restore 成功撤销改动
  [ ] 理解了：add 是"装书包"，commit 是"存档"

════════════════════════════════════
下一步：GitHub 作品集
════════════════════════════════════
  1. 注册 GitHub 账号：https://github.com
  2. 网页新建仓库（New repository）
  3. 把本地项目推上去：
       git remote add origin 仓库地址
       git push -u origin main
  4. 以后每次改完代码：
       git add .  →  git commit -m "说明"  →  git push
