# 📊 电商销售数据分析项目

> 一个完整的数据分析项目：从脏数据清洗到可视化报告。
> 技术栈：Python · Pandas · Matplotlib

---

## 📌 项目背景

模拟电商平台的订单数据，目标是**从原始销售数据中提炼业务洞察**，为采购与营销策略提供数据支撑。

**完整流程**：
```
原始数据（含脏数据）→ 数据清洗 → 多维分析 → 可视化 → 分析报告
```

## 🧹 数据清洗（核心环节）

原始数据包含 **5 类真实常见的数据质量问题**：

| 问题 | 数量 | 处理方式 |
|------|------|---------|
| 重复订单 | 2 行 | 删除重复 |
| "数量"缺失 | 2 行 | 关键字段缺失 → 删除 |
| "城市"缺失 | 3 行 | 非关键字段 → 填充"未知" |
| 类别名称含空格 | 3 行 | `.str.strip()` 清理（类别由 7 种纠正为 4 种）|
| 异常数值 | 3 行 | 负数量 / 0 单价 → 过滤 |
| 日期格式不统一 | 2 行 | `pd.to_datetime(format="mixed")` 统一 |

**清洗结果**：47 行 → **40 行**，缺失值 0，类别 4 种。

## 📈 核心发现

### 整体表现
- 总销售额：**8,148.60 元** ｜ 订单数：40 笔 ｜ 平均客单价：**203.72 元**

### 四个分析维度

| 维度 | 关键发现 |
|------|---------|
| **品类** | 水果占 55.2% 为第一；饮料单均最高（255.4 元）；蔬菜仅 4 单（样本不足）|
| **商品** | ⚠️ **樱桃单品占销售额 39.8%**，前 2 商品合计 66.4% → **集中度风险** |
| **时间** | 2 月销售最低，**但订单数最多（15 笔）**——实为客单价下降 30.9%，非"淡季" |
| **城市** | 北京/广州单均最高（250+ 元）；上海单均最低（119.7 元）但仅 5 单 |

### 核心建议
1. **降低单品依赖**：樱桃占近 4 成销售额，需扩展高单价商品线
2. **提升 2 月客单价**（而非减少采购）：2 月客流未减，问题在客单结构
3. **城市差异化策略**：暂不做关店决策，先排查原因
4. **蔬菜类先扩充品种**再评估（当前仅 2 个品种，无法判断需求）

## ⚠️ 数据局限（专业报告必备）
